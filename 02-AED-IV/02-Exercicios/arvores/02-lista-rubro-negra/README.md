# Lista 02 — Árvore Rubro-Negra (Aula 2)

Lista disponibilizada pelo professor Thamer Horbylon Nascimento no Moodle (AVA)
da disciplina **Algoritmos e Estruturas de Dados IV** (`Disciplina.0088`).

## Organização

- `00-enunciado/`: transcrição Markdown do enunciado oficial fornecido pelo
  professor. O PDF original também deve ser guardado nessa pasta quando estiver
  disponível.
- `01-questao-01/`: solução da questão 1 — árvore rubro-negra de números
  inteiros (inserção, percursos pré/em/pós-ordem, nós pares pretos e quantidade
  de nós vermelhos ímpares).

Materiais dentro de `apoio/` servem para estudo e não fazem parte da entrega no
Moodle, salvo orientação diferente do professor.

## Entrega (Moodle)

Arquivo único `.c` (nome do(a) aluno(a), ex.: `aluno.c`) compactado em `.zip`
ou `.rar` com o nome do(a) aluno(a).
