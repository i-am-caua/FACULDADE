# Questão 1 — Árvore Rubro-Negra

Crie uma árvore rubro-negra que armazene números inteiros com as seguintes
funções:

- a) Inserir.
- b) Funções que mostrem os valores e as cores dos nós com os percursos
  pré-ordem, em-ordem e pós-ordem.
- c) Mostrar o valor de todos os nós pares de cor preta.
- d) Mostrar a quantidade de nós vermelhos ímpares.

## Como compilar

```
gcc -Wall -Wextra -o questao-01-rubro-negra questao-01-rubro-negra.c
```

## Como executar

```
./questao-01-rubro-negra.exe
```
