Como Funciona a Inserção na Árvore Trie

O que é uma Árvore Trie (Árvore de Prefixos)?

A árvore Trie é uma estrutura de dados de árvore ordenada para armazenamento de strings. Diferente de uma árvore binária de busca, os nós da Trie não guardam a palavra inteira: cada nó representa um caractere ou prefixo compartilhado.

A Estrutura do Nó (struct No em C)

Em main.c, cada nó tem: 

typedef struct No {
    struct No *letras[26]; // 26 ponteiros para filhos ('a' a 'z')
    int palavra;           // 1 se termina uma palavra válida, 0 caso contrário
} No;

A Função Inserir Recursiva

A função recebe um ponteiro duplo No **raiz e o sufixo da palavra a inserir:

  1. Criação da raiz: se *raiz == NULL, aloca o nó raiz inicial.
  2. Cálculo de índice: index = palavra[0] - 'a' descobre qual ponteiro no vetor letras[26] corresponde à letra atual.
  3. Compartilhamento de prefixo: se (*raiz)->letras[index] == NULL, cria um novo nó filho; se já existir, aproveita o caminho existente!
  4. Caso Base: se palavra[1] == '\0' (última letra), marca o nó com palavra = 1 e retorna!
  5. Passo Recursivo: se ainda houver letras, chama inserir(&((*raiz)->letras[index]), palavra + 1) avançando na palavra.
