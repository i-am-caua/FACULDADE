# Questão 01 — Árvore Binária de Busca (BST)

Solução da primeira questão da lista de Árvores (BST e AVL), disponibilizada no
Moodle (AVA) da disciplina **Algoritmos e Estruturas de Dados IV**.

## Arquivos

- `questao-01-bst.c`: implementação da árvore binária de busca.
- `apoio/remocao-bst-visual.html`: simulação didática da remoção de um nó folha.

## Como compilar

No GCC:

```bash
gcc -Wall -Wextra -pedantic -std=c11 questao-01-bst.c -o questao-01-bst
```

## Como executar

Linux ou laboratório:

```bash
./questao-01-bst
```

Windows:

```powershell
.\questao-01-bst.exe
```

## Material de apoio

Abra `apoio/remocao-bst-visual.html` em qualquer navegador e use os botões
**Próximo passo** e **Voltar**. Os valores iniciados por `#` são endereços de
memória usados apenas para representação didática.
